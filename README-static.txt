Text Compare — ready-built static site

Upload ALL contents of this ZIP, including assets/ and .nojekyll, to a GitHub repository root or docs/ folder. In Settings > Pages choose Deploy from a branch, select that branch, then /(root) or /docs.

No build, login, API key or backend is needed. Do not open index.html directly with file://; serve over HTTP(S).

Comparison and processing run in the browser. Saved comparisons and drafts live in this browser only. Share URLs carry a compressed, readable snapshot; anyone with the link can read it. JSON export is the portable backup. Comments are snapshot annotations. PDF uses the browser print dialog. AI explanations and cloud collaboration are not implemented.

The source ZIP includes the GitHub Actions deployment workflow, tests, detailed README, REA analysis notes, and verification report.
