Text Compare — ready-built static site (audited 11 October 2026)

Upload ALL contents of this ZIP, including assets/ and .nojekyll, to a GitHub repository root or docs/ folder. In Settings > Pages choose Deploy from a branch, select that branch, then /(root) or /docs.

No build, login, API key or backend is needed. Do not open index.html directly with file://; serve over HTTP(S).

Comparison and processing run in the browser. Saved comparisons and drafts live in this browser only. Save updates the current library item; Save as copy creates another. Share URLs contain a readable snapshot; anyone with the link can read it. JSON export is the portable backup. Comments are local snapshot annotations. Results over 400 aligned rows are paginated without truncating input.

PDF uses Export > Print / PDF and the browser print dialog. Native PDF output has not been verified in the build environment. AI explanations and cloud collaboration are not implemented.

The matching source ZIP includes the GitHub Actions deployment workflow, 32 passing unit tests, 30 browser tests for CI, REA analysis notes, and a report of 119 passing live-browser assertions. See docs/VERIFICATION.md in that source ZIP for scope and remaining verification limits.
