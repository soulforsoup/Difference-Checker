Text Compare — ready-built static site (updated 12 October 2026)

Upload ALL contents of this ZIP, including assets/ and .nojekyll, to a GitHub repository root or docs/ folder. In Settings > Pages choose Deploy from a branch, select that branch, then /(root) or /docs.

No build, login, API key or backend is needed. Serve over HTTP(S), not file://.

Results appear above the editors, with clean per-side counts, Copy and compact merge arrows. Clear all is in the top toolbar. Editors scroll independently by default; Display > Sync scrolling optionally links them. New comparisons wrap long lines.

Saved comparisons and drafts live only in this browser. Save updates the current item; Save as copy creates another. Share URLs contain a readable snapshot; anyone with the link can read it. JSON export is a portable backup. Comments are local annotations. Results over 400 aligned rows are paginated without truncating input.

The source ZIP includes 34 passing unit tests, 34 browser tests for CI, REA analysis, and verification reports. The latest layout follow-up recorded 27 passing browser checks. Standalone browser tests were not run in the desktop sandbox. Native PDF output and exact CRLF clipboard delivery remain unverified; see docs/VERIFICATION.md in the source ZIP for details. AI explanations and cloud collaboration are not implemented.
